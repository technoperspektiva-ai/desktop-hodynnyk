# Desktop Hodynnyk — виправлення збереження та оновлення списку

Для репозиторію technoperspektiva-ai/desktop-hodynnyk.
Основа: d3d12967b85d3537e3875e65de2c84263953d51c.

## Встановлення
1. Розпакуйте ZIP.
2. Завантажте папки src і public в корінь desktop-hodynnyk із заміною файлів.
3. Дочекайтеся успішного Cloudflare deploy.
4. На першому пристрої відкрийте Desktop онлайн, закрийте його і відкрийте ще раз для завантаження оновленої версії.
5. Відкрийте Settings → About this Desktop → «Відновити локальні ресурси».
6. Підтвердіть перенесення відсутніх на сервері ресурсів зі старої локальної копії.
7. Відкрийте ту саму адресу Desktop на другому пристрої. Список оновлюється при поверненні у вікно та кожні 30 секунд, коли вікно видиме.

Не очищайте дані браузера на першому пристрої до відновлення.
Стара копія залишається під ключем desktop-hodynnyk:apps-before-sync-fix.
Повторне відновлення пропускає ресурси з однаковим ID або точною URL-адресою.
Відновлення може повернути раніше видалені ресурси, тому запускається лише за підтвердженням.

## Що виправлено
- Серверна помилка більше не замінюється удаваним успішним локальним збереженням.
- Локальний ресурс, якого ще немає у базі, створюється через POST при повторному збереженні.
- Додано відновлення старих локальних ресурсів без автоматичного перезапису серверних.
- Помилка завантаження спільного списку відображається у вікні.
- Додано повторне читання списку при поверненні, відновленні інтернету та через 30 секунд.
- Оновлено версію кешу оболонки.

## Перевірка
Автоматично перевірено логіку API з імітацією двох пристроїв, резервну копію, повторне відновлення без дублікатів, відхилені операції та створення старого локального ресурсу.
Повна збірка React та перевірка реального Cloudflare/D1 не виконувалися.
Якщо сервер повертає помилку після оновлення, вона стане видимою. Потрібно буде окремо усунути її причину, наприклад проблему підключення D1. Цей ZIP не змінює налаштування бази Cloudflare.
