# Desktop Hodynnyk — server + sync fix

Завантажте папки worker, src, public у корінь desktop-hodynnyk із заміною.
Цей архів включає попереднє виправлення синхронізації.

1. Дочекайтеся успішного деплою Cloudflare.
2. Відкрийте Desktop онлайн, закрийте його та відкрийте повторно для оновлення оболонки.
3. На першому пристрої: Settings → About this Desktop → Відновити локальні ресурси.
4. Відкрийте ту саму адресу Desktop на другому пристрої.

Не очищайте дані першого пристрою до відновлення.

Виправлено:
- Багаторядкові CREATE TABLE передаються окремими prepared statements через D1.batch замість exec, який розділяє запити за рядками.
- Ініціалізація початкових ресурсів використовує INSERT OR IGNORE для одночасного запуску.
- Відсутнє підключення DB має окреме зрозуміле повідомлення.
- Прибрано універсальну галочку з повідомлень, включно з помилками.
- Збережено попередні виправлення синхронізації та відновлення локальних ресурсів.

Якщо з’явиться DB_BINDING_MISSING: у Cloudflare → Workers & Pages → desktop-hodynnyk → Bindings підключіть наявну D1 базу як DB. Не створюйте нову замість наявної бази з даними.
Якщо з’явиться DESKTOP_DB_ERROR: потрібен текст відповідної помилки з журналу Worker. Секрети та токени не надсилайте.

Перевірено локально через SQLite та адаптер D1: створення таблиць, початкові записи, додавання ресурсу і читання окремим запитом, health та відсутність DB.
Перевірено клієнтську логіку резервної копії, відновлення без дублікатів, відхилених операцій і читання другим пристроєм.
Повна збірка React та перевірка на живому Cloudflare не виконувалися.
